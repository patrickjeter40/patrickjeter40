## 🔨 Selected projects

### Pathsmith — make decision workflows inspectable

A tool for creating, testing, and improving typed AI classification workflows. The full product combines visual editing, labeled examples, saved evaluation history, and AI-assisted configuration review.

**The public portfolio edition opens up the engine:** a runnable TypeScript sample with deterministic execution, exact-request mocks, and synthetic support-routing cases. It shows which path a decision took and which expectations a policy change broke.

> **One threshold change. Two regressions. One improvement.**
>
> Raising a routing threshold from `0.70` to `0.80` changes three outcomes across twelve synthetic cases. Both policies still reach every branch port—an example of why coverage alone doesn't tell you whether a change is good.

`TypeScript` `JSON Schema` `Deterministic workflows` `pnpm workspaces`

**[Explore Pathsmith's public portfolio →](https://github.com/patrickjeter40/pathsmith-portfolio#readme)**

<sub>The portfolio is a focused, offline runtime sample. The production application is maintained privately.</sub>

### Healthcare Dashboard — turn patient records into a usable workspace

A full-stack patient management application built around the everyday work of finding a patient, reviewing their history, and keeping records current.

Searchable records, clinical notes, validated forms, and deterministic patient summaries sit on top of a relational data model. Forty fictional patients and a Docker Compose setup make the project easy to explore locally.

**What to look for:** clear ownership of server and form state, validation across the UI and API, database migrations, and explicit handling of loading and error states.

`React` `TypeScript` `FastAPI` `PostgreSQL` `Docker Compose`

**[Explore the Healthcare Dashboard →](https://github.com/patrickjeter40/healthcare-dashboard#readme)** · [Architecture & decisions](https://github.com/patrickjeter40/healthcare-dashboard/blob/main/docs/architecture.md)

## 🧭 How I build

| **Making complexity usable** | Give forms, conditional workflows, and failure states the same attention as the happy path. |
